# Свернуть пункты сайдбара — плагин Agents Hub

Пункты над списком сессий (Расписание, Поток, Задачи, Неделя и другие плагины) сворачиваются в один «Разделы».
Клик по нему раскрывает их обратно. Открытый пункт остаётся виден и в свёрнутом виде. Состояние хранится в браузере;
по умолчанию свёрнуто.

Поставить: «Настройки» → «Плагины» → «Можно поставить» → fold-nav.
